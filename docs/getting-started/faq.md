# FAQ

### **What's the pricing? Do you accept crypto payment?**  
We suggest starting with the **Dev plan** license.  
For details on pricing tiers, usage quotas, and feature comparisons, visit our pricing page at **[codigo.ai](https://codigo.ai/)**.  

Prices can be paid with **credit card (USD)** or **crypto**. We accept crypto payments.

---

### **How is Código different from vibe‑coding platforms ?**  
Código is a **pro‑developer tool**: you own 100% of the code generated in your workspace, can review or modify it at any time, and retain full control. Unlike “no‑code” or vibe‑coding systems, we empower developers with **transparency, verifiability**, and full AI‑assisted code generation workflows.

---

### **Why should I use Código?**  
Our AI is **purpose‑built and trained exclusively on Solana development**, with over **40 million+ lines of secure, audited smart contract code**, making it far more reliable and context‑aware than generic AI tools.

---

### **What AI model is Código using?**  
Código is using 2 AI models:

- For Solana part, **Código AI Model** — our own AI trained from the ground up
- For Frontend part, **Anthropic**

### **Can I import my GitHub repo into Código and keep working?**  
Yes, absolutely. You can import:
- [**Public/Private repositories**](/guides/solana/start-from-github)  

Just clone your project in the terminal or use the GitHub import option when creating your workspace.

---

### **What programming languages does Código support?**
Código is purpose-built for **Solana development**, supporting:
- Rust  
- Anchor framework  
- TypeScript (for tests and frontend)
- Any frontend language

### **Can I share workspaces with a team?**  
Collaboration features such as shared workspaces, real‑time co‑editing, or role management are **coming soon** as part of our Enterprise and Team tiers.

---

### **Is my code secure and how is privacy handled?**  
Your workspace runs in a **cloud‑native sandbox with per‑workspace isolation**. We never sell or share your data. All AI models are self‑hosted and your code is owned solely by you.

---

### **Do I need coding experience to use Código?**  
It helps, but it’s not required. If you’re a beginner, Código is actually a great way to learn from clean, AI generated examples.  
👉 We recommend **starting from a template** to see how things are structured and build from there.
