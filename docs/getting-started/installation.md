# Installation

Getting started with Código is instant. No installation needed.

### How to start

1. Visit [**hub.codigo.ai**](https://hub.codigo.ai)  
2. Click **Sign Up** or **Login**  
3. Choose Email, Github, or Google to authenticate  
4. After login, click the **NEW** button to start your first workspace  
5. Start building your web3 project instantly

> No dependencies to install. No configuration required.
